Found a mistake? Please tell me.

This is the Quran, so every mistake matters and gets fixed first. If you see anything wrong, even something small, please report it: a missing or misplaced mark, a wrong word, a wrong ayah number, text cut off at a page edge, or a translation that does not match.

  • Which edition, and PDF or EPUB
  • The surah and ayah (e.g. 2:27), and the page number if it is a PDF
  • What is wrong, and a screenshot if you can
